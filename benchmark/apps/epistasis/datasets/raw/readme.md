# Epistasis -- Data Provenance

## Data Generation

All test data is synthetic. The canonical benchmark data are three `.bsdata`
tiers sized by `tier_config.py` and generated by
`datasets/tests/generate_tests.py --tier {small,medium,large}`. Random
bitstreams simulate binary SNP genotypes (allele-presence encoding):
`snp_a`/`snp_b` at ~50% density and a `valid` mask at ~94% density (modelling
missing data).

Real genotype data requires format conversion (e.g., via PLINK,
https://www.cog-genomics.org/plink/), and large biobank/GWAS cohorts such as
UK Biobank are controlled-access. Open reference panels such as the 1000
Genomes Project are freely available but are not GWAS phenotype cohorts.

## Ground Truth

Verified against a Python reference implementation of the 2x2 contingency
table: a scalar loop over individuals for the small fixed/random cases, and an
equivalent direct `popcount` for the large and tier cases.

## Datasets

Canonical tiers (read by the benchmark and test pipeline):

- **`tests/epistasis_tier_small.bsdata`** (133,000,000 individuals, ~50 MB)
- **`tests/epistasis_tier_medium.bsdata`** (1,330,000,000 individuals, ~500 MB)
- **`tests/epistasis_tier_large.bsdata`** (13,300,000,000 individuals, ~5 GB)
