# AES S-box -- Data Provenance

## Data Generation

All test data is synthetic. The canonical benchmark data are three
`.bsdata` tiers sized by `tier_config.py` and generated by
`datasets/tests/generate_tests.py --tier {small,medium,large}`: random
bytes stored as an 8-element bit-sliced stream array `U[0..7]` for the
Boyar-Matthews-Peralta / NIST CMT 113-gate circuit.
The AES S-box maps every byte independently, so random data is functionally
equivalent to any real file.

## Ground Truth

Exhaustively verified: all 256 input-output pairs checked against the
AES S-box lookup table (FIPS 197).

## Datasets

Canonical tiers (read by the benchmark and test pipeline):

- **`tests/aes_sbox_small.bsdata`** (~50 MB)
- **`tests/aes_sbox_medium.bsdata`** (~500 MB)
- **`tests/aes_sbox_large.bsdata`** (~5 GB)
