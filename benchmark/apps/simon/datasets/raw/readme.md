# SIMON 32/64 -- Data Provenance

## Data Generation

All test data is synthetic. The canonical benchmark data are three
`.bsdata` tiers sized by `tier_config.py` and generated by
`datasets/tests/generate_tests.py --tier {small,medium,large}`: random
plaintexts under the fixed SIMON paper key. SIMON is input-independent:
the same operations execute for any plaintext.

## Ground Truth

Verified against the published test vector from Beaulieu et al. (IACR ePrint
2013/404):

```
SIMON 32/64:
  Key:        1918 1110 0908 0100
  Plaintext:  6565 6877
  Ciphertext: c69b e9bb
```

## Datasets

Canonical tiers (read by the benchmark and test pipeline):

- **`tests/simon_small.bsdata`** (~50 MB)
- **`tests/simon_medium.bsdata`** (~500 MB)
- **`tests/simon_large.bsdata`** (~5 GB)

## References
