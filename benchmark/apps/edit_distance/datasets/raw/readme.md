# Edit Distance -- Data Provenance

## Data Generation

All test data is synthetic. The canonical benchmark data are three
`.bsdata` tiers sized by `tier_config.py` and generated by
`datasets/tests/generate_tests.py --tier {small,medium,large}`: random
DNA sequences over {A, C, G, T}. Myers' algorithm is input-independent:
the operation count depends only on N (text length) and M (pattern
length), not on the actual character values.

## Ground Truth

Verified against a Python scalar dynamic programming reference implementation.

## Datasets

Canonical tiers (read by the benchmark and test pipeline):

- **`tests/edit_distance_tier_small.bsdata`** (~50 MB)
- **`tests/edit_distance_tier_medium.bsdata`** (~500 MB)
- **`tests/edit_distance_tier_large.bsdata`** (~5 GB)

## References

- Myers, G. "A Fast Bit-Vector Algorithm for Approximate String Matching
  Based on Dynamic Programming." JACM 46(3), 1999.
