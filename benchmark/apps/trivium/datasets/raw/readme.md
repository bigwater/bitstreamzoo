# Trivium Stream Cipher -- Data Provenance

## Data Generation

All test data is synthetic. The canonical benchmark data are three
`.bsdata` tiers sized by `tier_config.py` and generated by
`datasets/tests/generate_tests.py --tier {small,medium,large}`: random
key/IV pairs.

## Ground Truth

Verified against the published ECRYPT test vector (De Canniere & Preneel 2006):

```
Key=0, IV=0 -> first 64 keystream bits = 0xFBE0BF265859051B
```

(ECRYPT eSTREAM Set 2, vector #0; cross-checked against the committed
`datasets/tests/ecrypt_vector_key=0_iv=0.bsdata` fixture and the Python
reference in `src/run.py`.)

## Datasets

Canonical tiers (read by the benchmark and test pipeline):

- **`tests/trivium_tier_small.bsdata`** (~50 MB)
- **`tests/trivium_tier_medium.bsdata`** (~500 MB)
- **`tests/trivium_tier_large.bsdata`** (~5 GB)
